# OPNsense Firewall Configuration

This project evaluates OPNsense as an open-source firewall and documents configuring and testing access controls in a virtual network.

## Work covered

- Allowing designated administration/client machines to reach firewall management services.
- Blocking other LAN hosts from the web interface and SSH.
- Reviewing firewall logs and evaluating brute-force protections and rate-limiting limitations.
