# AI Fundamentals: Network Traffic Analysis

This project report describes preparing network-session data for analysis and developing features to help distinguish normal traffic from potentially anomalous activity.

## Work covered

- Handling missing values in protocol and network-traffic fields.
- Standardizing protocol labels and selecting suitable imputation approaches.
- Engineering traffic features such as packet efficiency, session activity, and a combined risk score.
